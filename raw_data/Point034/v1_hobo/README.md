Déposer ici les copies byte-for-byte des exports HOBO historiques, sous les noms :
- `P_measures.csv`
- `T_measures.csv`

Sources historiques :
- `flipoyo/MOLONARI-data/SamplingPoints/Point034/point034_P_measures.csv`
