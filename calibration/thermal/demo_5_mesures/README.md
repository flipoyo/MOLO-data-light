# Jeu de démonstration — 5 mesures fictives

`RECORDS.csv` contient exactement cinq mesures artificielles au format brut RECORDS (sans en-tête, séparateur `;`).

Correspondance choisie pour la démonstration :
- `Value_Temperature_2` : température externe (°C) ;
- `Value_Temperature_3` : température interne (°C) ;
- `Value_Pressure` : pression (unité arbitraire cohérente pour l'exemple).

Les dates sont espacées d'une minute. Ces nombres ont été construits artificiellement pour produire un ajustement
numérique identifiable avec cinq points. Ils ne proviennent d'aucun capteur et ne doivent pas servir à calibrer
ou corriger des mesures réelles.

Pour lancer le parcours interactif, consulter la documentation `DEMO_CALIBRATION_THERMIQUE.md` dans
`MOLO-data-process` (branche `CGS-MOLO`).
